# Sazabi SDK

The official TypeScript SDK for the [Sazabi](https://sazabi.com) public API, published to npm as [`@sazabi/sdk`](https://www.npmjs.com/package/@sazabi/sdk).

## About

This is a release mirror. The SDK is developed in the private Sazabi monorepo; each release lands here as the exact content published to npm via [trusted publishing (OIDC)](https://docs.npmjs.com/trusted-publishers/). Do not commit directly — content flows here via automated release workflows and direct commits will be overwritten on the next release.
